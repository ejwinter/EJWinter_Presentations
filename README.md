# Presentations

A collection of presentations built with [Slidev](https://sli.dev).

## Running Any Presentation

Requires Node.js 18+.

```bash
cd <presentation-folder>
npm install
npm run dev
```

Opens the slides in your browser at `http://localhost:3030` with hot reload.

### Other Slidev commands

```bash
npm run build    # Build static site
npm run export   # Export to PDF
```

## Presentations

### [Agents_Context](./Agents_Context) — Beyond the Prompt

*Teaching Your AI to Think Like Your Team and Level Up with Skills*

Takes developers beyond prompt engineering into the structured techniques that make AI coding agents consistent and scalable across a team. Covers the paradigm shift from inline assistants to full coding agents, then the context guardrails that keep those agents on track: constitutions, memory, rules, skills, commands, and context hygiene.
